# Stock Portfolio Tracker 📈

## About the Project
The Stock Portfolio Tracker is a simple Python project developed as part of my internship task with **CodeAlpha**. It calculates individual stock investments and the total investment amount using manually defined stock prices and user-provided quantities.

## Features
- Enter the number of stocks.
- Input stock names and quantities.
- Calculate investment for each stock.
- Display the total portfolio investment.
- Save the portfolio report in a text file.

## Technologies Used
- Python
- Dictionaries
- Loops and Conditional Statements
- Basic Arithmetic Operations
- File Handling

## Stock Prices
The project uses predefined sample prices:

| Stock Name | Price per Share (₹) |
|---|---:|
| TCS | 3500 |
| INFY | 1500 |
| RELIANCE | 2500 |
| HDFC | 1700 |

*Note: These are manually defined sample prices, not live market prices.*

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python stock_portfolio_tracker.py
```

6. Enter the number of stocks, stock names, and quantities when prompted.
7. View the total investment in the terminal.
